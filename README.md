# 中国旅游地图 · 地级市版

一个交互式中国地级市旅游地图，支持精细化标记和在线分享。

## ✨ 功能特点

- **地级市精度**：覆盖全国 300+ 地级市
- **灵活标记**：5 种状态（未去过、很想去、去过、去过但还想去、不想去）
- **双重范围**：支持单个城市标记 / 整省批量标记
- **在线分享**：生成分享链接，无需注册账号
- **数据管理**：本地自动保存、导出/导入 JSON、数据合并
- **性能优化**：IndexedDB 缓存地图数据，第二次打开秒加载

## 🎨 使用方法

1. **选择状态**：点击顶部状态按钮（当前选中的会高亮）
2. **选择范围**：
   - 「单个城市」模式：点击地图标记单个城市
   - 「整个省」模式：点击地图标记整个省份
3. **上色**：用选中的状态"画笔"点击地图区域
4. **取消标记**：用相同状态再点一次，恢复为「未去过」

## 📤 分享功能

点击「📤 分享链接」按钮，链接会自动复制到剪贴板。别人打开链接后：
- **仅查看模式**：能看到你的标记，但不能修改
- 如需协作：导出 JSON 文件，通过云盘等方式交换，再导入合并

## 💾 数据说明

- **自动保存**：每次操作后自动保存到浏览器本地
- **导出格式**：JSON 文件，包含地区代码、状态和名称
- **导入合并**：导入他人数据时，会与现有数据合并（相同地区保留新值）
- **缓存机制**：首次加载需下载地图数据（~5MB），之后从缓存读取

## 🌐 部署方式

### 本地使用
直接用浏览器打开 `index.html` 即可

### 在线托管（推荐）
将文件上传到以下任一平台，即可获得固定访问链接：

1. **GitHub Pages**（免费）
   - 创建 GitHub 仓库，上传 `index.html`
   - 开启 Pages 功能
   - 访问 `https://你的用户名.github.io/仓库名/index.html`

2. **Vercel / Netlify**（免费）
   - 拖拽文件夹部署
   - 自动生成访问链接

3. **Cloudflare Pages**（免费）
   - 上传到 Git 或直接拖拽部署

> 💡 **OneDrive 不适合**：OneDrive 只能同步文件本身，浏览器本地存储不会同步，每个人看到的是自己的数据。推荐用在线托管 + 分享链接的方式。

## 🛠️ 技术栈

- **ECharts 5.4**：地图渲染和交互
- **DataV GeoAtlas**：阿里云地图数据 API
- **IndexedDB**：浏览器端地图数据缓存
- **LocalStorage**：用户标记数据持久化
- **URL Hash**：分享链接编码

## ⚠️ 注意事项

- 首次打开需联网加载地图数据（约 5MB）
- 清除浏览器缓存会丢失已标记数据，建议定期导出备份
- 分享链接只包含标记数据，不含地图本身
- IE 浏览器不支持，请使用 Chrome / Edge / Firefox

## 📊 数据格式

导出的 JSON 格式示例：
```json
{
  "110100": {
    "status": 2,
    "name": "北京市"
  },
  "330100": {
    "status": 1,
    "name": "杭州市"
  }
}
```

- `key`：6 位行政区划代码
- `status`：0=未去过, 1=很想去, 2=去过, 3=去过但还想去, 4=不想去
- `name`：地区名称（仅用于阅读）
